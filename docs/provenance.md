# Source and redistribution inventory

The owner authorized extraction of the Flowxtra accessibility/consent source interface. This project preserves its drawer width, teal header, grid controls, inline SVG geometry, banner buttons, tabbed preference panel, service tables and footer interaction. Intentional fixes include modal focus, reversible scope, event-driven state, validated expiry and actual SDK withdrawal. Source tracking IDs, endpoints, private storage keys, service inventory and legal-certification wording are excluded.

No Flowxtra/Dpro logo binary, Roboto/OpenDyslexic/Font Awesome font or third-party image is redistributed. Host logos are supplied by the installer and typography inherits. Inline icon geometry originates in the owner-supplied React files; those files contain no external icon import/license attribution. This inventory establishes source location, not proof of third-party authorship. Resolve any external provenance claim before representing the icons as independently owned. MIT covers the new implementation and owner-authorized source contributions subject to existing third-party rights.

Development dependencies include MIT-licensed TypeScript/esbuild/React/Vue/Svelte/Next/Astro/Express, Angular MIT, Python FastAPI MIT and Uvicorn BSD-3-Clause, and Laravel MIT. Their runtime packages retain their own notices; npm browser builds bundle no framework runtime, optional React remains external. WordPress is GPL; its standalone integration plugin uses the MIT code under GPL-compatible terms. Generated fixture bundles are build artifacts, not source assets copied from an unrelated project.

The two PNG compliance badges in docs/brand are Dpro-branded assets reused from Dpro-at/Tel-Agent at the owner's explicit request. They are displayed as owner-declared statements, not independent certifications. The source attribution is https://github.com/Dpro-at/Tel-Agent/tree/main/docs/brand/compliance.

Integration brand marks are from Simple Icons, distributed under CC0 1.0 (docs/brand/integrations/LICENSE.md). Brand names and marks remain subject to their owners' trademark guidelines; their appearance identifies tested integrations, not endorsement.
