# Changelog

## 0.1.0 — initial release candidate

- Framework-neutral validated accessibility/consent controllers with versioned storage and lifecycle events.
- Source-based drawer/banner and consent panel, isolated CSS, configurable locale/theme/brand/footer.
- SDK lifecycle gates, optional backend contract and Node/PHP/Python reference adapters.
- Frontend fixtures, WordPress plugin and bundled agent skill.
- Release support is limited to the evidence in docs/verification.md.
